# raw/ — material bruto

Coloque aqui, dentro de uma pasta por tema:

- transcrições de aulas e cursos;
- transcrições de vídeos do YouTube;
- artigos salvos (de preferência em Markdown);
- PDFs convertidos para texto;
- anotações de reuniões e palestras.

Regras:

1. Nome do arquivo com data ou número. Ex.: `2026-10-07-aula-03-meta-ads.md`.
2. Na primeira linha, escreva a origem (link, curso, autor).
3. Depois de entrar aqui, o arquivo não é mais editado.
4. Nada de senha, token, CPF ou dado de cliente.
